# 相続関係図くん (Relationship Diagram Generator)

## 概要 (Overview)
「相続関係図くん」は、主に司法書士事務所の事務員の方を対象とした、相続関係説明図の作成を支援するデスクトップアプリケーションです。ユーザーが相続人情報を入力することで、関係図を自動生成し、手動での調整も可能です。

## 主な機能 (Main Features)
*   **人物情報の入力**: 氏名、被相続人との続柄、生年月日、死亡年月日、本籍地、住所、生死、相続放棄の有無などを入力できます。
*   **選択式入力**: 続柄、生死の別、相続放棄の有無はリストから選択できます。
*   **日付入力支援**: 生年月日・死亡年月日はカレンダー形式（`QDateEdit`）で入力できます。
*   **家族構成テンプレート**:
    *   被相続人・配偶者・子供1人
    *   被相続人・子供2人
    の構成をワンタッチでリストに反映できます。
*   **相続関係図の自動生成**: 入力された人物情報に基づき、被相続人、配偶者、子（第一世代まで）の関係図を自動で描画します。
*   **図の編集**: 生成された図の各人物ノードはドラッグ＆ドロップで位置を自由に調整できます。
*   **データエクスポート**:
    *   人物情報をCSVファイルとしてエクスポートできます。
    *   表示されている相続関係図を画像としてExcelファイルにエクスポートできます。
*   **プロジェクトの保存・読み込み**:
    *   作成した人物情報、図のレイアウト情報、チェックリストの状態を独自の`.srk`形式（JSONベース）のファイルに保存し、後で読み込んで作業を再開できます。
*   **チェックリスト機能**: 相続手続きに必要な書類や作業項目を管理できるドッキング可能なチェックリストを備えています。チェック状態はプロジェクトファイルと共に保存されます。
*   **相続パターンガイド**: 一般的な相続パターンとその説明、法定相続分、注意点などを確認できるガイド機能が利用できます。
*   **データインポート**: CSVまたはExcel(.xlsx)ファイルから人物情報リストを一括読み込み。
*   **ダイレクトエクスポート**: 関係図をPNG画像またはPDFファイルとして直接保存。

## 技術スタック (Technology Stack)
*   **プログラミング言語**: Python 3.x
*   **GUIフレームワーク**: PyQt5
*   **Excelエクスポートライブラリ**: openpyxl

## 実行方法（ソースから）(How to Run from Source)
1.  **リポジトリのクローン** (リポジトリが公開されている場合):
    ```bash
    # git clone <repository_url>
    # cd <repository_directory>
    ```
2.  **必要なライブラリのインストール**:
    ```bash
    pip install -r requirements.txt
    ```
3.  **アプリケーションの実行**:
    ```bash
    python srz_kun/main.py
    ```
    (上記は `srz_kun` フォルダがカレントディレクトリの親にある場合の例です。適宜パスを調整してください。)

## プロジェクトファイル形式 (.srk) (Project File Format)
`.srk`ファイルはJSON形式で、以下の情報を含みます:
*   アプリケーションバージョン
*   人物情報リスト（各人物の属性詳細）
*   図のレイアウト情報（各人物ノードのX,Y座標）
*   チェックリストの各項目の状態（チェック済みか否か）

## パッケージング（配布用ファイル作成の概念）(Packaging - Conceptual)

このアプリケーションをスタンドアロンのWindows実行可能ファイルとして配布する場合、[PyInstaller](https://www.pyinstaller-doc.org/)のようなツールを使用できます。以下は概念的な手順です。

1.  **PyInstallerのインストール**:
    ```bash
    pip install pyinstaller
    ```

2.  **プロジェクトルートでの実行**:
    ターミナル（コマンドプロンプトやPowerShell）を開き、プロジェクトのルートディレクトリ（`srz_kun`フォルダや`README.md`がある場所）に移動します。

3.  **PyInstallerの実行**:
    *   **単一ディレクトリ形式の場合（推奨される最初の試み）**:
        ```bash
        pyinstaller --name 相続関係図くん --windowed --noconfirm srz_kun/main.py
        ```
    *   **単一ファイル形式の場合（起動が遅くなる可能性あり）**:
        ```bash
        pyinstaller --name 相続関係図くん --onefile --windowed --noconfirm srz_kun/main.py
        ```
    *   `--name`: 生成される実行可能ファイルやフォルダの名前を指定します。
    *   `--windowed`: GUIアプリケーションのため、実行時にコンソールウィンドウを表示しません。
    *   `--noconfirm`: PyInstallerが既存のビルドファイルを上書きする際に確認を求めないようにします。
    *   **注意**: アプリケーションが画像ファイルやデータファイルなどの外部アセットに依存している場合（このプロジェクトの現在のバージョンでは該当しませんが、将来的に追加された場合）、それらをPyInstallerのスペックファイルで指定するか、`--add-data`オプションを使用する必要があるかもしれません。また、`openpyxl` や `PyQt5` の一部モジュールが自動的に検出されない場合は、`--hidden-import` オプションが必要になることもあります。

4.  **成果物**:
    `dist` という名前のフォルダがプロジェクトルートに作成されます。このフォルダ内に `相続関係図くん` というサブフォルダ（単一ディレクトリ形式の場合）または `相続関係図くん.exe` ファイル（単一ファイル形式の場合）が格納されます。

5.  **テスト**:
    `dist` フォルダ内の実行可能ファイルを、開発環境とは異なるクリーンなWindows環境でテストし、正しく動作することを確認します。

6.  **インストーラーの作成（オプション）**:
    さらにユーザーフレンドリーな配布形式としてインストーラーを作成したい場合は、[Inno Setup](https://jrsoftware.org/isinfo.php) や [NSIS](https://nsis.sourceforge.io/Main_Page) といったツールを使用して、`dist` フォルダの内容を含むインストーラーパッケージを作成できます。
